USAGE: fluxr <help|SUBCOMMAND> [OPTION]

SUBCOMMANDS:
    host-sync [OPTION]
        <HOSTNAME> Run sync only for this host
        -a         Sync all configured hosts

    remote-sync [SOURCE] [TARGET]
        Without arguments it will sync all configured remotes.
        SOURCE and TARGET syntax must be rclone compatible. See (https://rclone.org/docs/#syntax-of-remote-paths)

    help
        Show this help text
